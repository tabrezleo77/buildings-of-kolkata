# Kolkata Heritage 🏛️

A modern and interactive website that showcases the architectural heritage of Kolkata, also known as the **City of Palaces**. The project highlights iconic landmarks, architectural styles, historical timelines, and includes an engaging quiz to enhance the learning experience.

## ✨ Features

* Modern, responsive UI
* Dark & Light mode toggle
* Interactive landmark gallery
* Filter buildings by architectural style
* Historical timeline of Kolkata's iconic structures
* Interactive architecture quiz
* Detailed modal view for each landmark
* Smooth scrolling and animations

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Lucide Icons
* Google Fonts
